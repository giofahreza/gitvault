Notes

How-to guides
Applies to
Web, Android, Windows, macOS, and Linux
Updated
August 1, 2026

Use encrypted Markdown notes for private documents, linked knowledge, daily logs, reusable templates, and task lists.

Create a note

  1. 1
    Open Notes.

    Use the Notes tab or menu item.

  2. 2
    Select add.

    Choose a blank note, built-in template, or encrypted saved template.

  3. 3
    Add a title and Markdown.

    Use Edit for source and Preview for rendered headings, lists, links, code, quotes, tables, and tasks.

  4. 4
    Return to Notes.

    The editor autosaves encrypted changes and shows its save status.

Write tasks and linked knowledge

  • Tasks Write - [ ] Open task or - [x] Completed task. Cards show task progress.
  • Note links Use [[Note title]] or [[Alias#Heading|label]]. Preview opens resolved targets.
  • Backlinks The editor lists direct links and unlinked title or alias mentions from other notes.
  • Blocks End a line with an anchor such as ^decision-1, then reference it with ((decision-1)).
  • Outline Open the document outline to jump to a Markdown heading.

Use daily notes and templates

Open the Notes action menu for Daily notes, the knowledge graph, and template management. Daily notes keep one journal per calendar date. Built-in templates cover daily logs, meetings, and projects; saved templates remain encrypted and synchronize as hidden note records.

Import or export Markdown

Import .md, .markdown, or .txt files from the Notes action menu. Export from the editor writes one Markdown file with structured front matter for title, aliases, tags, color, pin state, and journal date.

Exports are decrypted.

An exported Markdown file is outside GitVault encryption. Protect, move, or delete it according to the sensitivity of the note.

Organize notes

  • Pin Keep important notes at the top.
  • Color Use color as a quick visual category.
  • Tags Add tags such as #work or #finance when search should find a note by context.
  • Aliases Add alternate names that wiki links and MCP clients can resolve.
  • Archive Hide old notes without deleting them.

Find notes

Use search for title, Markdown content, aliases, and tags. Card previews remove Markdown punctuation and show task counts. The knowledge graph visualizes resolved note links. Derived link, backlink, and graph indexes stay only in memory while decrypted notes are available.

Legacy checklists

Older checklist records render as canonical Markdown without changing encrypted storage. Editing one saves it as Markdown while preserving every task and completion state.

Archive or delete

Archive notes you may need later. Delete only when you are sure, then sync so other devices receive the delete tombstone.
