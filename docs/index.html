The data path

A simple route for secrets.

Your repository is useful storage. It is not asked to become a password manager.

  1. 01

    Write locally

    Create a password, note, code, or SSH entry on a device you control.

  2. 02

    Seal it first

    GitVault applies authenticated XChaCha20-Poly1305 encryption before sync begins.

  3. 03

    Store ciphertext

    Your private repository receives encrypted files and sync history, not a readable vault.

Security, made legible

No hidden vault service. No ambiguous owner.

GitVault makes the trust boundaries visible, so you can see who is responsible for each part of your vault.

A quieter first setup

Bring your own key.
Bring your own repository.

Start a vault in the web app, protect it with a PIN, and save the recovery phrase outside GitVault. Connect a private repository when you want encrypted backup or another trusted device.
