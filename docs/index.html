Security model

A repository is storage, not trust.

Boundary What happens
Your device
Creates the vault key, encrypts records, and holds your recovery phrase.
GitHub
Stores encrypted vault files in a repository you control.
GitVault
Has no hosted vault service, account database, or readable copy of your secrets.
You
Choose the repository, approve devices, and retain responsibility for your recovery phrase.

Read the complete security model before putting secrets in any password manager.

First setup

Bring your own repository.

There is no hosted GitVault account to create. Start with your own GitHub account and a private repository.

  1. 1
    Create a private repository

    An empty repository in your normal GitHub account is enough.

  2. 2
    Open GitVault and save recovery

    Create the vault key, record the recovery phrase, and set your unlock method.

  3. 3
    Connect encrypted sync

    Add a fine-grained GitHub token and approve additional devices when you are ready.
